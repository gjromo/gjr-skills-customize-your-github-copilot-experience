# 📘 Assignment: Data Structures in Python

## 🎯 Objective

Explore the core Python data structures used to organize and manage information. In this assignment, students will practice using lists, dictionaries, sets, and tuples to solve practical programming problems.

## 📝 Tasks

### 🛠️ Work with lists and tuples

#### Description
Create a program that stores and manipulates a collection of student names, scores, or items using lists and tuples.

#### Requirements
Completed program should:

- Use a list to store multiple values in order
- Use a tuple for a fixed collection of data, such as coordinates or a record
- Add, remove, or update items in the list
- Print the contents in a readable format
- Explain how the chosen data structure helps solve the problem

### 🛠️ Organize data with dictionaries

#### Description
Build a small contact book, inventory, or roster that stores related information using key-value pairs.

#### Requirements
Completed program should:

- Use a dictionary to map keys to values
- Add new entries and update existing ones
- Look up values by key
- Remove an entry when requested
- Display the full dictionary in a clear format

### 🛠️ Use sets for unique values

#### Description
Write code that tracks unique items, such as favorite books, tags, or event attendees.

#### Requirements
Completed program should:

- Use a set to store only unique values
- Add and remove elements from the set
- Find common elements between two sets or compare differences
- Display the final set contents
- Show why a set is useful for avoiding duplicates
