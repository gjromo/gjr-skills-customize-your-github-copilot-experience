# 📘 Assignment: Statistics with Python

## 🎯 Objective

Use Python to explore data and calculate basic statistics. This assignment introduces students to descriptive statistics using tools such as pandas and NumPy to summarize, compare, and interpret data.

## 📝 Tasks

### 🛠️ Load and inspect data

#### Description
Read a dataset into Python and examine its structure before calculating statistics.

#### Requirements
Completed program should:

- Load a CSV file using pandas
- View the first few rows of the dataset
- Check the number of rows and columns
- Identify the columns available for analysis
- Explain the purpose of the dataset in a few sentences

### 🛠️ Calculate descriptive statistics

#### Description
Use NumPy and pandas to calculate summaries that describe the dataset.

#### Requirements
Completed program should:

- Compute the mean, median, and mode for numeric columns
- Find the minimum and maximum values
- Calculate the standard deviation or variance when relevant
- Display results in a readable format
- Identify which statistic is most useful for the selected data

### 🛠️ Visualize and interpret findings

#### Description
Create a chart or summary table to communicate the dataset’s trends and insights.

#### Requirements
Completed program should:

- Generate at least one chart using matplotlib or pandas plotting tools
- Label the chart clearly with a title and axis names
- Highlight a key trend or pattern from the data
- Write a short interpretation of the results
- Describe what the statistics reveal about the dataset
