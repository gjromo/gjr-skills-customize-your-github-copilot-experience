# 📘 Assignment: Python Data Visualization

## 🎯 Objective

Create simple charts and graphs in Python using matplotlib or Plotly to turn raw data into a visual story. This assignment helps students practice data representation, formatting, and interpreting trends in a visual way.

## 📝 Tasks

### 🛠️ Create a basic chart

#### Description
Build a Python script that reads a list of values and creates a simple line or bar chart.

#### Requirements
Completed program should:

- Use matplotlib or Plotly to generate a chart
- Include labels for the x-axis and y-axis
- Add a title to the chart
- Plot at least 5 data points
- Display the chart in a browser or notebook window

### 🛠️ Compare data visually

#### Description
Create a chart that compares two related data sets so differences or trends are easy to see.

#### Requirements
Completed program should:

- Plot two datasets on the same graph or in side-by-side charts
- Use different colors or styles for each series
- Include a legend explaining each dataset
- Make the chart readable and easy to interpret
- Save the chart as an image file if requested

### 🛠️ Interpret the results

#### Description
Write a short summary explaining what the chart shows and what conclusions can be drawn from it.

#### Requirements
Completed program should:

- Describe the main trend or pattern in the chart
- Note any surprising or important values
- Explain how the visualization helps communicate the data
- Include a few sentences in plain language for a general audience
