# 📘 Assignment: Python Text Processing

## 🎯 Objective

Learn how to work with strings, read and write text files, and manipulate content in Python. This assignment introduces common text-processing techniques such as cleaning input, counting words, and extracting useful information from files.

## 📝 Tasks

### 🛠️ Read and analyze a text file

#### Description
Create a Python program that reads a text file and calculates basic information about its contents.

#### Requirements
Completed program should:

- Open a text file from disk using Python file I/O
- Count the total number of words in the file
- Count the number of lines and characters
- Display the results clearly in the console
- Handle missing files with a friendly error message

### 🛠️ Clean and transform text

#### Description
Write functions that clean up text by removing unwanted characters, normalizing spacing, and converting case as needed.

#### Requirements
Completed program should:

- Remove extra spaces and blank lines from a string
- Convert text to lowercase or title case when requested
- Replace repeated whitespace with a single space
- Preserve important punctuation while cleaning the content
- Demonstrate the cleaned output on sample text

### 🛠️ Search and extract information

#### Description
Build a simple text-processing utility that finds keywords or patterns within a document.

#### Requirements
Completed program should:

- Ask the user for a word or phrase to search for
- Count how many times the search term appears in the text
- Highlight or print matching lines from the file
- Ignore case differences when comparing text
- Display a result summary at the end of the program
