# 📘 Assignment: Python Functions and Modules

## 🎯 Objective

Learn how to write reusable Python code with functions and organize related code into modules. This assignment helps students move from simple scripts to cleaner, more maintainable programs that can be reused across tasks.

## 📝 Tasks

### 🛠️ Write and call functions

#### Description
Create a Python script that defines and uses functions to complete a few small tasks.

#### Requirements
Completed program should:

- Define at least three functions with clear names
- Use parameters and return values effectively
- Call the functions from the main program flow
- Display the result of each function in a readable way
- Keep the code organized and easy to understand

### 🛠️ Build a reusable calculator

#### Description
Write a small calculator program that uses functions for each operation.

#### Requirements
Completed program should:

- Include functions for addition, subtraction, multiplication, and division
- Accept input values from the user
- Return results from each function
- Handle division by zero with a friendly message
- Print the final answer in a neat format

### 🛠️ Organize code with modules

#### Description
Split reusable code into separate files and import them into a main script.

#### Requirements
Completed program should:

- Create a separate module file with helper functions
- Import the module into the main program
- Use at least one function from the module in the script
- Keep the main file focused on user interaction and output
- Explain how modules make programs easier to maintain
